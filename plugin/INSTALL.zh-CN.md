# FHAssist 0.6：锁头 / 锁身体、地图与自动开火（实验版）

仅适配 FINAL HOUR 0.2.10 / 0.4172 的指定 Mach-O UUID。
用新版 FHAssist.dylib 替换旧版，彻底退出游戏后重开；不要同时注入多个版本。
本次 GitHub 构建产物名为 FHAssist-0.2.10-arm64，安装后应看到 **FH 0.6** 面板。

默认只显示屏幕边缘的半透明 FH 小按钮，设置与报告收起。
点击 FH 展开紧凑面板，点击“收起”或再次点击 FH 隐藏面板；展开期间会暂停瞄准与自动点射。
拖动 FH 可调整位置，位置会保存；旋转屏幕后保持在安全区域内。诊断报告仍在面板中，点文字可复制。

展开后的控制：

- **地图敌人**：原生地图敌人常显，默认关。
- **锁头**：搜寻 150 米内、角差不超过 60 度的存活非友方，读取真实 head 骨骼位置。
  本版检查多个骨骼网格及子角色，默认关；头骨骼不存在就跳过，不用固定高度代替。
- **锁身体**：与锁头为两个独立按钮，但只能启用一个瞄准部位；优先使用 `spine_03`，
  不存在时依次检查 `spine_02`、`spine_01` 的真实骨骼位置。躯干骨骼都不存在则跳过，绝不回退锁头。
  再点当前已开启的部位可关闭瞄准；两种瞄准默认都关闭。
- **地图比例**：默认缩小 2 倍。地图框不变、显示的距离范围变为 2 倍，
  同一段移动在图上的位移约减半；可点击恢复原比例。不会调整人物移动速度。
- **自动开火**：默认关，沿用当前锁头/锁身体；未选部位时默认选锁头。
  本版改为严格点射，不持续按住开火。必须同时满足：
  - 真实镜头射线的第一个阻挡命中是当前敌人，不能是墙、队友或另一个目标。
  - 命中点距所选头骨骼不超过 12cm，或距所选躯干骨骼不超过 40cm。
  - 镜头角差按距离收紧（头部以 6cm、身体以 15cm 投影计算），最多 0.35°。
  - 同一角色、同一部位连续满足条件至少 150ms；中断、遮挡、切换部位均重新确认。
  每次点射请求至少间隔 200ms，调用游戏原生 TryFire；武器冷却、弹药、模式及服务端规则仍有效。
  玩家已经按住手动开火时不发送自动点射，也不替玩家松开手动输入。

**展开 FH 设置面板时暂停瞄准和自动开火；收起后重新确认目标，满足条件才继续。**
这与旧版“收起仅改变显示”不同。普通关闭面板不会关闭开关，但恢复前会重新累计稳定时间。

## 怎么知道生效

开关“搜敌中”不等于已经锁到敌人。看下方实时报告，点文字可复制后粘贴反馈：

| 报告 | 含义 |
|---|---|
| HUD 回调未运行或已暂停 | 绘制回调没有持续到达，锁头逻辑未必执行 |
| 未获取到本地角色/镜头 | 本地控制器或观察点不可用 |
| 敌 N、骨骼 0 | 找到了存活敌人，但所查网格没有当前所选部位的骨骼 |
| 范围 0 | 骨骼候选超出了角度/距离条件 |
| 可见 0 | 没有候选通过原生视线检查 |
| 写视角不断增加 | 已调用视角接口，并读回确认控制旋转字段与请求一致 |
| 上次射线：命中所选部位 | 最近一次准星射线首先命中当前角色，命中点也在所选部位附近 |
| 上次射线：遮挡或命中其他对象 | 第一命中对象不是当前角色，不发送点射请求 |
| 上次射线：命中点偏离所选部位 | 命中角色但没有打在所选骨骼附近，不发送点射请求 |
| 点射请求 N | 累计调用原生 TryFire 的次数，不代表实际发射次数或命中次数 |
| 自动开火：面板内暂停 | 设置面板展开，自动点射不会执行 |

范围/可见统计是网格候选数，同一敌人可能贡献多个候选。
写视角计数不能证明最终镜头采用了该旋转；报告同时显示真实镜头与目标的角差。如计数上涨仍不转向，需要继续核对实际镜头更新入口。
报告不包含命中验证，也没有上传设备日志。

## 验证边界

GitHub 上执行数学/恢复/开火条件测试、iOS arm64 编译和签名检查；
当前服务器不编译、不启动游戏或插件。用户已反馈此前版本可用，
用户已反馈 0.5 有时误开火；0.6 点射与精确射线条件尚未在设备上复验，不能把编译成功称作误开火已彻底解决。

搜敌仍使用角色整体视线检查；自动点射另外验证真实镜头射线的第一阻挡和命中点。
该射线使用游戏 Visibility 碰撞通道，不能保证与每种武器的枪口路径、穿透或服务端判定完全一致。
超出原地图范围或未同步到客户端的角色无法凭空显示。
切到后台会关闭瞄准和自动开火。本版不持有跨帧开火按下输入，HUD 停止就不会再发送新的点射请求。
如持续开火或状态异常，关闭自动开火并退出对局/游戏，移除此 dylib 可恢复原游戏。
