# FHAssist 注入插件

适用样本：FINAL HOUR 0.2.10，构建 0.4172，包标识 com.aggames.finalhour。
插件还会校验 Mach-O UUID 和两处函数特征；相同版本号但不同二进制不保证兼容。

## 安装

1. 在 GitHub 的 Actions → Build iOS plugin → 最近一次成功运行中下载 `FHAssist-0.2.10-arm64` 产物。
2. 解压，取出 `FHAssist.dylib`。
3. 在你的巨魔注入器中选择 FINAL HOUR，添加该 dylib，并按注入器的流程保存/安装。
4. 完全退出游戏后重新打开。进入前台后应出现可拖动的 `FH` 按钮。
5. 点击 `FH`，开启“启用增强”。初始默认关闭，设置不跨启动保存。

本产物是普通 arm64 iOS 动态库，无需 MobileSubstrate、Substitute、ElleKit 或越狱路径。由 GitHub macOS runner 交叉编译并 ad hoc 签名；注入器仍需完成其安装和签名流程。未生成重新打包的 IPA。

## 功能

- 增强已有的跟瞄，调整距离（20–150 米）、目标捕获范围（20–200 厘米）与跟随强度（0.5–2.0）。
- “仅开镜时启用”默认打开；关闭后仍受游戏其他原有条件限制。
- 默认跟随强度 1.0、距离 80 米、捕获范围 80 厘米；开启时同时把原生 Slow 参数设为 0.25。
- 关闭“启用增强”会恢复本次开启前的值；如果某个值已被游戏改变，则保留游戏后续修改。
- 版本不匹配时禁用开关，显示“此游戏版本不支持”。

这一版是原生瞄准辅助增强，不包含独立目标扫描、自动开火、指定头部、穿墙或强制解除静止/移动判定。实际效果依赖游戏本身的目标选择和状态；尚未在真机注入验证。

## 使用问题

- 看不到 FH 按钮：先确认注入器确实加载 dylib，完全退出重开；记录注入器名称、版本、iOS 版本及崩溃日志（如有）。
- 显示不支持：提供实际使用的 IPA 版本与构建信息；插件不会尝试套用其他版本的地址。
- 有按钮但无明显跟随：到训练场中开镜，轻微移动或调整视角；原有跟随逻辑保留了这些条件。可先把跟随强度调高，核对效果。

编译和桌面参数测试在 GitHub Actions 完成；iOS 注入、场景旋转和实际瞄准效果需要真机验证。
