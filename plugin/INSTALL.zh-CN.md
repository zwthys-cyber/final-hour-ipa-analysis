# FHAssist：小地图敌人持续显示（实验版）

仅适配 FINAL HOUR 0.2.10 / 0.4172 的指定 Mach-O UUID。
本版将复杂跟瞄设置替换为一个开关，不再调整跟瞄参数。

1. 从本次 GitHub Actions 的 `FHAssist-0.2.10-arm64` 构建产物下载 dylib 或 ZIP。
2. 用注入工具把 `FHAssist.dylib` 添加到游戏，彻底关闭后重新启动。
3. 点击屏幕上方中央的“地图敌人：关”，开启后为“地图敌人：开”。
4. 左上角原生地图按原有旋转、缩放和范围绘制已同步至客户端的存活敌人位置，
   不要求敌人先开火。关闭开关后停止临时标记。

“等待对局”表示尚未找到支持的原生 HUD；进入对局或换图后每秒重试。
“版本不支持”时不启用修改。开关默认关闭，不保存上次状态。

所有静态反汇编、测试、iOS 编译及签名检查在 GitHub runner 上执行。
尚未进行真机注入或实战验证；编译通过不等于真机功能已验证。
若注入后出现崩溃，可先移除此 dylib 恢复原游戏；不要同时注入旧版 FHAssist。

限制：无法显示服务器未同步到客户端的角色，也不扩大原地图覆盖范围。
此实现仅覆盖指定原生 AFHHud 类；其他 HUD 类型不会被替换。
技术实现及临时写入的边界见 `MINIMAP_RESEARCH.zh-CN.md`。
